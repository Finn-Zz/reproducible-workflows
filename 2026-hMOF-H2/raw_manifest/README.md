# Raw-data access

The raw RASPA archives are too large for ordinary GitHub storage. Upload them to the lab's approved storage, Zenodo, or another shared location, then replace the placeholder below with the download URL or folder link:

> **Raw-data URL:** `PASTE_SHARED_RAW_DATA_LINK_HERE`

The archive names, expected sizes, and SHA-256 values are listed in [`raw_archives_manifest.tsv`](raw_archives_manifest.tsv). The repository contains the normalized 432-CIF input set and all parsed v5 tables; the external raw-data location supplies the full RASPA stdout/restart history.

If the raw folder is access-controlled, grant the professor access explicitly. Do not publish cluster credentials, private keys, or site-specific account settings.
